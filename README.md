# Programming Exercises – Python

This package contains all 10 exercises from the supplied programming laboratory material, organized into separate exercise folders.

Each exercise contains its own `README.md`, and each individual program is provided as a Python `.py` file using the requested naming style (`ex1a.py`, `ex1b.py`, etc.).

## Structure

- `Ex1/` – Operators
- `Ex2/` – Decision Making and Loops
- `Ex3/` – Matrix Operations
- `Ex4/` – Functions
- `Ex5/` – Recursion
- `Ex6/` – Strings and Pointer Concepts
- `Ex7/` – Structures
- `Ex8/` – Structure Array
- `Ex9/` – Union
- `Ex10/` – Random Access File Banking System

## Running a program

Use Python 3:

```bash
python Ex1/ex1a.py
```

The same pattern applies to every `.py` file in the package.
