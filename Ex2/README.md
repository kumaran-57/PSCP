# Exercise 2 — Basic Number Programs

Programs included:

## 2a — Prime Numbers
- File: `ex2a.c`
- Aim: Find whether a given number is a prime number or not.

## 2b — Generation of Numbers Not Divisible by 2, 3 and 5
- File: `ex2b.c`
- Aim: Generate numbers between 1 and 100 which are not divisible by 2, 3 and 5.

## 2c — Leap Year
- File: `ex2c.c`
- Aim: Find whether the given year is a leap year or not.

## Source fidelity

These C files are based directly on the programs in the supplied document. The source code is preserved wherever it is valid; only necessary corrections were made where the document code was not correct or would not compile/work safely with a modern C compiler.
