# Exercise 2: Decision Making and Loops

2a checks primality, 2b generates numbers from 1 to 100 not divisible by 2, 3, and 5, and 2c checks leap years.

## Programs

- `ex2a.py` – Prime Numbers
- `ex2b.py` – Generation of Numbers Not Divisible by 2, 3 and 5
- `ex2c.py` – Leap Year

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex2/ex2a.py
```

Enter the requested values when prompted.
