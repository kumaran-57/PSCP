# Exercise 8: Structure Array

Stores and displays multiple book records using a list of Book data-class objects, equivalent to an array of structures.

## Programs

- `ex8.py` – Data Organization for Multiple Items Using a Structure Array

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex8/ex8.py
```

Enter the requested values when prompted.
