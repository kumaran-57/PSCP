# Exercise 7: Structures

Computes internal marks for five subjects using a Student data class, equivalent to the structure-based organization in the source exercise.

## Programs

- `ex7.py` – Compute Internal Marks of Students for Five Different Subjects Using Structures

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex7/ex7.py
```

Enter the requested values when prompted.
