# Exercise 1 — Operators and Calculations

Programs included:

## 1a — Operator-Based Calculation and Comparison
- File: `ex1a.c`
- Aim: Demonstrate arithmetic, relational, and logical operators to perform calculations and comparisons on integer values.

## 1b — Assignment and Conditional Operators
- File: `ex1b.c`
- Aim: Demonstrate assignment operators and the conditional operator.

## 1c — Bitwise Swap
- File: `ex1c.c`
- Aim: Demonstrate bitwise operators to swap two values without a temporary variable.

## Source fidelity

These C files are based directly on the programs in the supplied document. The source code is preserved wherever it is valid; only necessary corrections were made where the document code was not correct or would not compile/work safely with a modern C compiler.
