# Exercise 1: Operators

1a, 1b, and 1c cover arithmetic/relational/logical operations, assignment and conditional operators, and a bitwise XOR swap.

## Programs

- `ex1a.py` – Operator-Based Calculation and Comparison
- `ex1b.py` – Assignment and Conditional Operators
- `ex1c.py` – Bitwise Swap

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex1/ex1a.py
```

Enter the requested values when prompted.
