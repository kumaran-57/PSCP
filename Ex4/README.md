# Exercise 4: Functions

4a generates a Fibonacci sequence using a function, while 4b checks whether a number is an Armstrong number using a function.

## Programs

- `ex4a.py` – Fibonacci Sequence Up to a Given Number Using Function
- `ex4b.py` – Armstrong Number Using Functions

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex4/ex4a.py
```

Enter the requested values when prompted.
