# Exercise 3: Matrix Operations

3a performs matrix addition, 3b performs matrix subtraction, and 3c performs matrix multiplication with dimension checking.

## Programs

- `ex3a.py` – Matrix Addition of Two Numbers
- `ex3b.py` – Matrix Subtraction
- `ex3c.py` – Matrix Multiplication

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex3/ex3a.py
```

Enter the requested values when prompted.
