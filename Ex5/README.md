# Exercise 5: Recursion

5a calculates the sum of digits recursively, 5b calculates factorial recursively, and 5c solves Towers of Hanoi recursively.

## Programs

- `ex5a.py` – Sum of Digits of a Positive Integer Using Recursion
- `ex5b.py` – Factorial of a Given Number Using Recursion
- `ex5c.py` – Towers of Hanoi Using Recursion

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex5/ex5a.py
```

Enter the requested values when prompted.
