# Exercise 9: Union

Demonstrates the idea of storing one selected employee-data type at a time. Python does not have a direct C-style union, so a small data class represents the active member.

## Programs

- `ex9.py` – Storing Employee Data Using Union

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex9/ex9.py
```

Enter the requested values when prompted.
