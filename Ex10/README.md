# Exercise 10: Random Access File Banking System

Provides account creation, update, delete, deposit, withdrawal, and account listing using fixed-size binary records and direct file seeking.

## Programs

- `ex10.py` – Inserting, Updating, Deleting, and Appending Customer Details in a Banking System Using Random Access File

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex10/ex10.py
```

Enter the requested values when prompted.
