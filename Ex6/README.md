# Exercise 6: Strings and Pointers

6a finds string length, 6b concatenates two strings, and 6c checks whether a string is a palindrome. The Python versions express the pointer logic with indexes because Python does not expose C-style pointers.

## Programs

- `ex6a.py` – Find the Length of the String
- `ex6b.py` – Concatenate Two Strings Using Pointers
- `ex6c.py` – Check the Given String is a Palindrome

## Requirements

- Python 3.8 or newer is recommended.
- No external Python packages are required.

## How to run

From the project root, run for example:

```bash
python Ex6/ex6a.py
```

Enter the requested values when prompted.
